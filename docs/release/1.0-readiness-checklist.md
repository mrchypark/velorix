# 1.0 Readiness Checklist

Velorix 1.0 readiness is based on the jarless materialized view runtime.

Required release inputs:

- S3-compatible benchmark gate evidence
- production readiness evidence
- production GC evidence
- RustFS production GC validation evidence
- ingest-writer lifecycle evidence
- standing-runtime product evidence
- release image digests for `velorix-api`, `velorix-meta`, and the Hiqlite
  authority image

Required checks:

```bash
cargo deny -f json check -W unmaintained
cargo run -p velorix-cli -- dependency-governance-validate \
  --manifest dependency-governance.json \
  --cargo-deny-json target/dependency-governance/cargo-deny.jsonl \
  --json
cargo run -p velorix-cli -- release-status-validate \
  --status-matrix docs/architecture/production-readiness-status.md
```

The readiness report must validate relation catalog, object-store capability,
checkpoint lifecycle, state substrate, DataFusion policy, table registry,
materialized view runtime, benchmark, Kubernetes, GC, and dependency governance
status.

Standing-runtime product evidence must prove the REST relation/create ingest
view/query flow, restart recovery, committed-epoch consistency, and fail-closed
admission for unsupported views.
